# sponsor-page 表示ルール

## 1. 基本方針

`sponsor-page` のコミュニティ別メンバー一覧は、詳細説明の場所ではなく、ユーザーが相談先・訪問先を素早く選ぶための商品棚として扱う。

一覧では情報を盛りすぎず、誰が何の人なのかが一目でわかる表示を優先する。

詳細説明、経歴、サービス内容、CTA、注意書きは、各メンバー詳細ページ側に記載する。

## 2. メンバー一覧カードの表示形式

メンバー一覧カードは、原則として以下の形式に統一する。

役割・相談内容 + 氏名／名称

表示例：

法律相談の池田龍吾
企業型DC相談の比留間将弘
オーダースーツの金井
美容相談の美容西川
相続・事業承継の尾形明夫
経営相談の矢野惠一
ワインバーのザ・ワインベース銀座
三味線奏者の矢吹和之
AIインテグレータの高村榮一

## 3. 一覧カードで避けること

一覧カードでは、以下を原則使わない。

- 長い説明文
- 長いサブタイトル
- 2行以上の補足説明
- サービス内容の詳細説明
- 経歴説明
- 強い営業文句
- 複数肩書きの羅列
- `<small>` を使った補足説明の多用
- 説明文用の不要な `<span>` 構造

理由：

一覧がゴテゴテして読みづらくなり、ユーザーが選びにくくなるため。

## 4. 一覧ページと詳細ページの役割分担

### 一覧ページに置くもの

- 短い役割名
- 氏名または屋号
- カテゴリ分類
- 詳細ページへのリンク
- 右側の `›` 導線

### 詳細ページに置くもの

- 紹介動画
- 基本情報
- 相談できる内容
- こんな方に
- 特徴
- CTA
- 注意書き
- 公式サイトやLINE導線

## 5. カテゴリ分類ルール

現時点の基本分類は以下。

### 飲食

- ザ・ワインベース銀座

### 美容・ファッション

- オーダースーツの金井
- 美容西川

### 相談

- 池田龍吾
- 比留間将弘
- 尾形明夫
- 矢野惠一
- 高村榮一

### その他

- 矢吹和之
- その他、飲食・美容ファッション・相談に入らない活動、文化、ファンコミュニティ系

## 6. 実装ルール

`ginza-six.html` などのメンバー一覧では、以下を守る。

- カード内はできるだけ1行表示にする
- 長文説明はHTMLから削除する
- 不要な説明文用CSSは残さない
- 右側の `›` 導線は維持する
- タブ分類は維持する
- スマホ幅で見やすいことを優先する
- 一覧カードの高さが不必要に大きくならないようにする

## 7. 新規メンバー追加時のチェック項目

新規メンバーを追加するときは、以下を確認する。

- 一覧表示名が短いか
- 役割が一目でわかるか
- 詳細説明を一覧に入れていないか
- カテゴリが適切か
- 詳細ページへのリンクが正しいか
- スマホ表示で読みやすいか
- 既存メンバー一覧と見た目の粒度が揃っているか

## 8. 判断基準

迷った場合は、以下を優先する。

1. 一覧は短くする
2. 詳細は個別ページに逃がす
3. スマホで読みやすくする
4. 相談・行動導線を邪魔しない
5. 見た目を商品棚として整える

## 9. 今後の扱い

今後、`ginza-six.html` や他コミュニティページにメンバーを追加・修正する場合は、このルールを参照すること。

一覧ページを説明文で膨らませず、詳細ページ側で内容を充実させる。
